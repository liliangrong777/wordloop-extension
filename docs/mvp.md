# MVP 头脑风暴

原则：尽可能短。只证明「再遇见」会发生。掌握、课文、PDF 全部往后放。

配套：`product-brainstorm.md` 看全局，`ops.md` 看装完之后怎么来人，`tech.md` 看选型。

## 只做这 6 件

1. Onboarding：装完 3 分钟内完成「划一个词 → 看到它会再亮」
2. 划词收藏：释义、发音（有免费再用）、URL、原句；跳过译文节点
3. 再遇见：之后的英文页高亮已收藏词
4. 词表：看、删、跳回出处
5. 导入：先吃 txt 一词一行、csv（词 / 释义 / 原句）
6. 邮箱验证码登录 + 词表进云；未登录也能先用

另外带上：Chrome + Edge 同一套；每周最多一次轻提醒（可关）；首次真实高亮后的求评弹层（文案见 `ops.md`）。

## Onboarding（冷启动，比登录更重要）

词表为空时，高亮不会发生。第一天必须把词表养活。

建议脚本：

1. 引导固定插件图标
2. 打开一篇英文示例页（或用户当前英文页）
3. 让用户划 1 个词并收藏
4. 立刻演示：该词在页内被高亮，点开能看到释义和原句
5. 提示可导入旧词表；提示登录后换设备不丢

不要用这一步去触发商店求评。

未决：示例页用我们托管的一篇，还是就地用用户当前页。

## 收藏

- 划词即可收藏，记下词、免费词典释义、免费发音（没有就先不做）、页面 URL、原句
- 不把沉浸式翻译等插件的译文当原文收藏
- 与沉浸式翻译并存，不复制整页翻译
- 沙拉查词是竞品，不拼查词深度，拼再遇见

## 再遇见

- 之后浏览时高亮词表中的词
- 点击高亮：释义 + 当年原句
- 一页过多时要能关本页或做简单上限，避免卸载
- 形态还原、词义消歧：能顺手做再做，不挡发布

## 导入

用来缩短「空词表 → 第一次再遇见」的时间。

第一版建议只保证：

- `.txt` 一词一行
- `.csv`：词、释义、原句

沙拉查词 / 单词收藏助手的专用导出：有稳定格式再适配，不进第一刀。

## 登录

- 邮箱 + 6 位验证码（不做微信，避免开放平台 / 小程序）
- 本机先能收藏和高亮，登录后云同步
- 强制先登录会把 Onboarding 断在验证码上，不这么做
- 登录比微信轻，但仍要国内服务器、HTTPS、发信；先做离线闭环再接

未决：未登录期间产生的词表，登录后如何合并。细节见 `tech.md`。

## 平台

- Chrome 商店 + Edge 商店
- 官网离线包：国内装不上商店时再补，不进 MVP

## 明确砍掉

| 砍掉 | 原因 |
|---|---|
| AI 生成课文 | 后期；用户可自己把词表丢给 GPT |
| 掌握 / 测验 / 词状态 | 中后期 |
| 词根、联想记忆 | 内容工程大 |
| PDF | 有需求再做；研究生读论文先不当承诺 |
| YouTube / Netflix | Language Reactor 已很强 |
| 小程序 | 另一条产品，且单词收藏助手已做 |
| 国际化 | 前期不做 |
| 收费 | 为爱发电 |
| 官网安装包 | 可后补 |

## 技术备忘

选型正文在 `tech.md`。这里只留和范围相关的：

- 方案 A：WXT 插件 + Next.js 后端，国内服务器
- 本机 `chrome.storage.local` 是主；接口只做登录后同步
- 词典：免费数据 / API，国内用户最好有中文释义
- 发音：有免费再用
- 模型已有，留给后期课文
- 事件尽量不传整页；可记词、是否命中、域名类别
- 权限会要读页面，商店和用户都要能看懂「为了高亮你收藏的词」

## 怎样算 MVP 做成了

- Chrome、Edge 都能装
- Onboarding 能跑完「划词 → 高亮」
- 7 日内出现真实高亮命中（先内部看数）

只收藏、几乎不再遇见：先改 Onboarding / 导入 / 高亮，不进入掌握和课文，也不加大投放。

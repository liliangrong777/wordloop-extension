# 运营思路

前期为爱发电，预算上限 1 万元。先靠内容和社群装进第一批人，再用真实「再遇见」换商店评价，最后才吃商店搜索量。前期不考虑国际化。

## 原则

- 社群和内容只服务「真实阅读里再遇见」，不运营泛英语打卡。
- 要评价，不要诱导好评：不奖励、不按满意度分流、不和功能挂钩。
- 第一次在真实网页里看到自己的词被高亮，才是开口的时刻。
- 商店冷启动不能只押评价；0 评价时主流量在小红书和社群。

## 冷启动顺序

1. Chrome + Edge 能装、Onboarding 能跑完「划词 → 高亮」。
2. 小红书 / 一个微信群带录屏和商店链接，装进第一批人。
3. 这批人发生真实再遇见后，留下商店评价。
4. 商店搜索（网页高亮生词、阅读中复习）开始接量。
5. 有成品后再碰视频区评论、阮一峰周刊。

## 渠道

| 渠道 | 怎么用 | 何时做 |
|---|---|---|
| 小红书 | 「收藏后第几天又在文档里亮了」的前后对比，不讲功能清单 | 有能安装的版本就做 |
| 社群 | 单一主阵地；入群尽量绑定已收藏 / 已命中；每周一次「本周再遇见」 | 同上 |
| Chrome / Edge 商店 | 标题和首图强调再遇见；评价入口按浏览器分开 | 上架时备好 |
| 视频区、阮一峰周刊 | 补充曝光，不当主渠道 | 有成品、有基本评价之后 |
| Onboarding 结束页 | 「发给一个也在读英文的人」 | 随 MVP |

不作为主渠道：到处开群、评论区灌水、用课文或功能换评价。

## 社群

不要做成又一个英语学习群，否则人和产品断开。

- 主题只留：遇见故事、一词多现场、后期才有的课文共读。
- 入群门槛尽量绑产品行为：安装、收藏满 N 个、或分享一次再遇见。
- 能做：内测、自愿评价、功能反馈。
- 不做：每日催打卡、群里换五星、把群当客服垃圾桶。
- 「默默」和鸡血社群是反的，低频高质量。

## 求评（要流量，但不诱导好评）

Chrome / Edge 商店冷启动确实靠评价数。要的是真实评价，不是假五星。刷评、只让满意的人去商店、好评解锁功能，都可能被砍权重或下架。

### 时机

- 用户自己收藏的词，在后来的真实网页里被高亮之后再问。
- 不要用 Onboarding 示例页触发。
- 每人最多 2 次；点过「去商店」后不再弹。
- 与每周学习提醒错开，不要同一天叠出来。

### 弹层文案

**第 1 次**

- 标题：这个词又出现了
- 正文：你收藏的「{word}」刚在这篇里再次出现。如果这对你有用，去商店写一句真实使用感受就行，能帮后面的人找到它。
- 按钮：去商店写评价 / 以后再说

**第 2 次**（「以后再说」后至少隔 14 天，且再次真实高亮）

- 正文：又碰到「{word}」了。愿意的话，去商店留一句真实感受。

主按钮按浏览器走对应商店评价页。不问满不满意，不出现五星。已去过商店后，只在词表页留一条很淡的「去商店评价」。

### 商店详情

- 标题：默默背单词 - 阅读时再遇见收藏的词
- 短描述：划词收藏后，之后读英文网页时会高亮这些词。看见自己的词再次出现，比把单词丢进词表更有用。
- 详情第一段讲再遇见，不催打卡。评价引导只放功能列表后面一句：用过之后，欢迎在商店写下真实感受，好的坏的都可以。
- 第一张截图：英文段落里高亮收藏词，点开能看到原句。配文：收藏过的词，会在你以后读的英文里再次亮起。

前 20 条评价无论几星都回复。

## 商业（现在不收，以后再收）

- 前期为爱发电，不收费。
- 高亮本身很难收费；以后若收费，更可能是课文额度、同步增强，而不是高亮。
- 课文生成是后期；也接受用户把词表自己丢给 GPT。不要用课文承担冷启动求评。
- 用户量起来后，再做成养活自己的小生意。

## 指标（给运营看的）

未登录也能先看安装级数据；邮箱登录后看用户级。登录方式见 `tech.md`。

- 安装后是否完成第一次收藏
- 7 日内是否发生至少 1 次真实高亮命中（核心）
- 导入是否完成
- 求评展示次数、去商店点击、是否关掉提醒
- 商店评价数和回复是否跟上

没有「再遇见」，先改 Onboarding / 导入 / 高亮，不加大投放。

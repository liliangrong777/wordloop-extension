# 产品头脑风暴

原始提纲在 `product.md`。这里记录讨论后的判断：哪些留下、哪些推迟、哪些还没拍板。技术选型见 `tech.md`。

## 一句话

把你收藏过的词，送回你每天已经在看的英文网页里。前期只保证「再遇见」，不保证「已掌握」。

## 主题（从原提纲收束）

原想法有两条：

1. 通过不断重复出现加深印象
2. 用 AI 生成文章加深印象

当前取舍：先做 1。AI 课文是后期；用户把词表丢给 GPT 生成文章，可以接受，不挡着我们。

「默默」：不刷题、不打卡排行。可以轻提醒（例如一周一次「本周 N 个词再次出现」），可关闭。

## 用户

原提纲：国内上班族、研究生。过宽。

插件真正前提：每天会打开英文网页的人。

- 先做：读英文文档 / 技术文章 / 网页资料的上班族、研究生
- 第一版不做：几乎只读 PDF 论文的人（PDF 有需求再做）
- 非目标：只刷题、几乎不读英文网页的人

小程序「碎片化背单词」和插件「浏览时再遇见」是两条产品。第一年不做小程序，避免直接撞墨墨 / 不背单词。

## 产品形态

- 默默背单词浏览器插件（Chrome + Edge，同一套）
- 国内装不上商店时，官网安装包后期再补
- 仓库名 Wordloop，对外名暂用默默背单词；商店、小红书、口播需要同一个名字（名称仍可再定）

## 阶段

| 阶段 | 承诺 | 做什么 |
|---|---|---|
| 前期 / MVP | 遇见 | 见 `mvp.md` |
| 中后期 | 掌握 | 词状态、复习、怎样算学会 |
| 后期 / 有需求再做 | 增强 | AI 课文、PDF、小程序、词根词缀、联想记忆、YouTube / Netflix、国际化、收费 |

## 竞品

| 产品 | 它是什么 | 我们不同在哪 |
|---|---|---|
| 沙拉查词 | 查词为主，生词本为辅 | 主路径是再遇见，不是查完即走 |
| 单词收藏助手 | 网页收藏 + 微信登录 + 小程序刷词 | 不靠小程序刷卡，靠回到真实网页里再亮出来 |
| 沉浸式翻译 | 阅读基建，不是背词产品 | 必须共存；只收藏原文，不收藏译文 |
| ChatGPT | 后期课文的替代品 | MVP 不拼课文；接受用户自己生成 |

单词收藏助手已经做了微信登录 + Chrome/Edge。再做一套登录不构成差异，差异只能落在「再遇见」是否真的发生。

## 能力取舍（头脑风暴池）

留下、进 MVP 的，见 `mvp.md`。这里只记大池子。

**收藏与词表**

- 划词收藏；释义、发音、出现位置、原句
- 导入旧词表（冷启动很关键）
- 词根词缀、联想记忆：后期
- 短语 / 搭配要不要收：未决，MVP 先按单词

**再遇见**

- 页面高亮已收藏词
- 形态还原（running → run）：值得做，但实现成本另估
- 高亮密度：一页太多会毁阅读，要有上限或关本页
- 错义（bank 银行 / 河岸）：掌握阶段再认真做
- PDF、飞书、Google Docs：PDF 明确后期；其它站点能亮就亮，不承诺

**课文**

- 用用户自己的词 + 原句语境生成短文，比通用 GPT 更有理由
- 现已有模型，但生成文章仍是后期
- 接受用户导出词表去 GPT

**提醒与掌握**

- 轻提醒：学习用，不是鸡血打卡
- 学会的定义未拍：遇见 N 次 / 用户标记认识 / 不再点开 / 干脆不宣称学会
- 词状态（新词 / 熟悉 / 已掌握）放中后期

## 登录、数据、预算

- 要登录，MVP 用邮箱验证码。登录为了同步，不为开门：未登录必须能收藏和高亮。
- 微信登录推迟：标准扫码要开放平台，个人变通又要小程序，不值得为同步先养一套。
- 指标：匿名 `install_id` + 登录用户。核心看 7 日真实高亮命中。
- 词典用免费的；发音有免费就用免费。
- 合规和法律先跳过；数据尽量少传，不传整页 HTML。
- 为爱发电投入上限 1 万元。先留域名、国内服务器、HTTPS、邮件。用户量起来后再做成养活自己的小生意。
- 栈：WXT 插件 + Next.js 后端（方案 A），见 `tech.md`。

## 还没拍板

- 对外最终名称
- 导入第一版吃哪些格式（建议先 txt 一词一行 + csv）
- 未登录数据如何在登录后合并
- 免费词典具体用哪一套（中文释义对国内用户很重要）
- 「学会」在中后期怎么定义

## 明确不做（至少到 MVP 之后）

小程序、PDF、AI 课文、掌握体系、YouTube / Netflix、国际化、收费、深挖合规。
